# veang-workbench-ui

Internal workbench surface for [Veang Workbench](../../README.md). Install the `veang-workbench` bundle instead of this package directly.

In Veang Workbench `0.2.x`, this source is embedded into the main package during release — the server entry as `veang-workbench/ui`, the client entry as `veang-workbench/client` — and is not published separately.
